# 커뮤니티 홍보 글 초안

아래 내용을 그대로, 또는 커뮤니티 분위기에 맞게 다듬어서 올리시면 됩니다.
(개발자 커뮤니티용/일반 커뮤니티용 두 버전을 준비했어요.)

---

## 버전 1 — 일반 커뮤니티용 (맘카페, 지역 커뮤니티, SNS 등)

**제목: 부모님・조부모님이 키오스크 앞에서 헤매지 않으시도록, 다 같이 만들어요 🙏**

안녕하세요. 요즘 병원, 은행, 식당 어디를 가도 키오스크(무인 기계)부터 마주치는데, 어르신들껜
여전히 큰 장벽이더라고요. 그래서 **카메라로 키오스크 화면을 비추면 AI가 "지금 여기를
누르세요"라고 알려주는 무료 웹앱**을 만들고 있어요. 설치도 필요 없고, 큰 글씨・음성 안내까지
지원해요.

그런데 지금은 안내 문구를 일반적으로 알려진 정보로 작성한 단계라, **실제 화면과 조금 다를 수
있어요.** 그래서 부탁드려요 —

여러분이 병원 접수기, 은행 ATM, 패스트푸드 키오스크를 이용하실 때 **화면 사진 한 장만 찍어서
보내주시면** 안내를 훨씬 정확하게 만들 수 있어요. (다른 분 얼굴이나 카드번호, 결제금액 같은
개인정보만 안 나오게 찍어주시면 돼요!)

제보는 여기서 간단하게 할 수 있어요 👉 [화면 제보하기](https://github.com/rmj84/world/issues/new?template=kiosk-screenshot.yml)

작은 사진 한 장이 누군가의 부모님께 큰 도움이 될 수 있어요. 관심 가져주셔서 감사합니다 🙇

---

## 버전 2 — 개발자・기술 커뮤니티용 (OKKY, 디스콰이엇, GeekNews 등)

**제목: [사이드 프로젝트] 노년층용 키오스크 AI 안내 앱 — 실제 화면 데이터 제보를 구합니다**

카메라로 키오스크 화면을 찍으면 Claude Vision이 화면을 인식해서 다음에 눌러야 할 버튼 위치를
사진 위에 하이라이트로 표시해주는 노년층 대상 접근성 웹앱을 만들고 있습니다 (Next.js 14 +
Tailwind, PWA).

지금 병원/ATM/패스트푸드 3종의 안내 흐름은 공개된 정보를 바탕으로 작성한 상태라, 실제 키오스크
화면과 어긋나는 부분이 있을 수 있습니다. 이용해보시고 실제 화면 스크린샷을 제보해주시면(개인정보
제외) 프롬프트와 안내 데이터를 더 정확하게 다듬는 데 큰 도움이 됩니다.

- 제보 양식(GitHub Issue Form): https://github.com/rmj84/world/issues/new?template=kiosk-screenshot.yml
- 코드/PR 기여도 환영합니다.

접근성에 관심 있으신 분들의 피드백과 제보 부탁드립니다 🙏

## 공통 체크리스트 (올리기 전에)

- [ ] 링크가 실제로 열리는지 한 번 클릭해서 확인
- [ ] 개인정보(전화번호, 실명 등) 노출 없는지 확인
- [ ] 커뮤니티 규칙상 "홍보성 글"이 허용되는 게시판인지 확인 (금지된 곳에 올리면 삭제될 수 있어요)
